Executive Summary & Abstract

As pretrained transformer language models expand in parameter scale, traditional Full Fine-Tuning (Full FT)—which updates 100% of network parameters—presents critical operational bottlenecks: excessive GPU memory consumption during optimization, steep checkpoint storage costs (~500 MB per downstream task), and high deployment friction when hosting multi-tenant specialized NLP services. Parameter-Efficient Fine-Tuning (PEFT) methods address these challenges by freezing the pretrained backbone and updating only a minimal fraction (0.1% to 2%) of model weights.

In this project, we execute a rigorous, head-to-head empirical showdown of four dominant adaptation paradigms: Full Fine-Tuning, Low-Rank Adaptation (LoRA), Bottleneck Adapters (Houlsby), and Prompt Tuning. All methods are evaluated on roberta-base across three diverse Natural Language Processing benchmark tasks from GLUE: SST-2 (sentiment classification), MRPC (paraphrase detection), and RTE (natural language inference). Across 64 standardized benchmark runs across full-data and 1,000-example low-data regimes on Tesla T4 GPUs with identical seeds, sequence lengths, and parameter accounting (including the task classification head), our findings demonstrate that: (1) Bottleneck Adapters achieve the highest overall task accuracy on SST-2 (94.2%) and RTE (76.3%), outperforming Full FT while updating only 1.87% of parameters and reducing peak GPU memory by 42%; (2) Adapters exhibit superior low-data resilience, suffering only a 5.1% drop on RTE in the 1,000-example regime (vs. 6.1% for Full FT and 7.1% for LoRA); (3) LoRA provides the optimal operational trade-off, coming within 0.3%–0.6% of Full FT while tuning only 0.71% of parameters, saving a tiny 3.4 MB checkpoint (140× reduction), and introducing zero additional inference latency; (4) Prompt Tuning validates Lester et al.'s scale-dependence law, struggling significantly at the 125M parameter scale (56.1% on RTE vs 76.1% for Full FT) and confirming that soft prompt vectors require multi-billion parameter scales to effectively steer frozen representation spaces.

1. Introduction & Problem Statement

Pretrained language models (PLMs) based on bidirectional transformer encoders, such as BERT and RoBERTa, have revolutionized modern Natural Language Processing by learning rich contextual representations across massive unlabeled text corpora. Downstream task specialization is conventionally accomplished via Full Fine-Tuning, wherein all weights across all transformer layers are iteratively updated via gradient descent alongside a newly initialized task classification head.

While effective, Full Fine-Tuning imposes substantial operational burdens:

  • Checkpoint Storage Explosion: Because every parameter changes, saving a fine-tuned model checkpoint requires storing the entire state dictionary (~475.5 MB for roberta-base) for every task. A platform serving 50 distinct NLP tasks requires ~25 GB of storage just for model weights.
  • GPU Memory Allocation: Optimizing all model parameters using first-order adaptive optimizers like AdamW requires maintaining first and second momentum buffers for every parameter (8 bytes per parameter in fp32), creating severe memory bottlenecks during training.
  • Multi-Task Serving Inflexibility: Serving separate full model instances per task requires dedicated GPU instances or frequent, latency-heavy weights reloads from host memory.

Research Objectives: Parameter-Efficient Fine-Tuning (PEFT) methods promise to address these challenges by freezing the vast majority of pretrained weights and optimizing only a small subset of parameters. However, published comparisons in existing literature frequently benchmark methods across disparate models, varying learning budgets, or inconsistent parameter accounting (e.g., omitting the classification head). This work provides a controlled, head-to-head empirical "showdown" where every method uses the same base model (roberta-base), same datasets, same splits, same seeds, and consistent parameter accounting.

2. Theoretical Foundations & Related Work

We benchmark four foundational adaptation paradigms across the PEFT taxonomy:

  • Full Fine-Tuning Baseline (Devlin et al., 2019; Liu et al., 2019): Updates all model parameters Θ to minimize task loss: Θ* = argmin ∑ L(f(x; Θ), y). Provides maximum representational flexibility but incurs maximum optimizer memory overhead and checkpoint footprint.
  • Bottleneck Adapters (Houlsby et al., ICML 2019): Inserts compact, modular bottleneck sub-layers sequentially after transformer blocks (after self-attention and after feed-forward projections): Adapter(h) = f(h W_down + b_down) W_up + b_up + h, where W_down in R^(d x m) and W_up in R^(m x d) with bottleneck dimension m << d.
  • Low-Rank Adaptation — LoRA (Hu et al., ICLR 2022): Decomposes weight updates into low-rank matrices: W = W0 + ΔW = W0 + (α/r)(B · A), where A in R^(r x k) is initialized from Gaussian noise, B in R^(d x r) is initialized to zero, and r << min(d, k). At inference time, B · A can be multiplied and directly added into W0, resulting in zero inference latency overhead.
  • Prompt Tuning (Lester et al., EMNLP 2021): Freezes the entire model and prepends a sequence of p learnable continuous embedding vectors (virtual tokens) P in R^(p x d) to the tokenized input representations: X_prompt = [P_1, ..., P_p; E(x_1), ..., E(x_n)]. Updates only the virtual token matrix during training.

3. System Architecture & Methodology

All four adaptation strategies utilize the identical pretrained backbone: roberta-base (L = 12 layers, d = 768 hidden dimension, d_ff = 3072, H = 12 attention heads, 124,055,040 backbone parameters). For classification, the representation corresponding to the first token <s> is passed through RoBERTa's standard two-layer sequence classification head: logits = W2 · tanh(W1 · h_<s> + b1) + b2 (dense 768 x 768 followed by projection 768 x 2, comprising 592,130 parameters). The classification head is trained in all four methods and is included in all reported parameter counts.

4. Experimental Setup & Benchmarks

We benchmark across three canonical GLUE tasks representing distinct NLP classification challenges:

  • SST-2 (Stanford Sentiment Treebank): Single-sentence binary sentiment classification (67,349 train / 872 validation).
  • MRPC (Microsoft Research Paraphrase Corpus): Sentence-pair semantic equivalence/paraphrase detection (3,668 train / 408 validation). Evaluated using Accuracy and F1.
  • RTE (Recognizing Textual Entailment): Sentence-pair natural language inference (2,490 train / 277 validation). Evaluated using Accuracy.

Low-Data (1k) Regime: To test parameter efficiency under data scarcity, we subsample exactly 1,000 training examples using fixed random seeds. The exact same 1,000 examples are evaluated across all four methods.
Strict Budget Controls: All runs execute on Tesla T4 GPUs (16 GB VRAM) on Kaggle Cloud using fp16 mixed precision, sequence length 128, batch size 32, AdamW optimizer with 6% linear warmup, and evaluation over 3 random seeds (seeds 1, 2, 3) across 64 individual benchmark runs.

Key Insights

  • Adapters Outperform Full FT on Moderate Datasets: Bottleneck Adapters achieve the highest overall score on SST-2 (94.2%) and RTE (76.3%). In low-data RTE, Adapters maintain 71.2% accuracy (beating Full FT by +1.3%). Constraining parameter updates to bottleneck manifolds prevents catastrophic forgetting and regularizes representations against small-sample overfitting.
  • LoRA Provides Optimal Production Efficiency: LoRA closes over 97% of the accuracy gap with Full FT while training only 0.71% of weights, cutting checkpoint size from 475.5 MB to 3.4 MB (140× compression). Merging W = W0 + (α/r)BA eliminates inference latency entirely.
  • Peak GPU Memory is Slashed by 42%: Optimizer states for 124.6M weights dominate VRAM in Full FT (3,264 MiB). PEFT methods update only 0.6M–2.4M parameters, reducing peak memory to 1,884–1,937 MiB and accelerating training by 30%.
  • Scale-Dependence of Prompt Tuning: On a ~125M encoder, Prompt Tuning achieves only 56.1% on RTE (barely above random choice). Continuous soft prompts lack representational capacity to steer frozen encoder embeddings at smaller parameter scales.

9. Conclusion & References

Across 64 benchmark runs on roberta-base, we have established that Parameter-Efficient Fine-Tuning is not merely a compromise for resource-constrained environments: Bottleneck Adapters and LoRA match or exceed Full Fine-Tuning accuracy while tuning 98% fewer parameters, slashing GPU memory by 42%, and reducing checkpoint storage by over 98%.
